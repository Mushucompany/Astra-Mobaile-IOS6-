# Astra Launcher

Лёгкий Android-лаунчер в стиле **iOS 6** — замена домашнего экрана для телефона. Показывает установленные приложения сеткой 4×4 и доком из 4 иконок, с тёмно-синим Aqua-фоном, статус-баром и глянцевыми значками.

## Возможности

- **Замена домашнего экрана** — при установке Android предлагает сделать Astra Launcher домашним экраном по умолчанию.
- **Сетка приложений 4×4** — все запускаемые приложения с иконками и подписями, отсортированные по алфавиту.
- **Док на 4 иконки** — быстрый доступ к часто используемым приложениям.
- **Стиль iOS 6** — тёмно-синий градиентный фон, статус-бар, глянцевые значки.
- **Живое обновление** — список и док пересобираются при возврате в лаунчер (`onResume`).

## Vue в духе iOS 6

- Тёмно-синий обойный градиент (`#0c1e3f`).
- Статус-бар: время слева, сигнал, батарея.
- Док с полупрозрачным тёмным фоном.
- Сетка приложений 4×4, значки масштабируются под устройство.

## Технологии

- **Язык:** Java (Android)
- **Минимальная версия Android:** 5.0 (API 21)
- **Target SDK:** 34 (Android 14)
- **Сборка:** Gradle 8.2, AGP 8.2.0, Java 17
  
## Сборка

Проект собирается без IDE, напрямую через Gradle:

```
JAVA_HOME=<путь к JDK 17>
C:\Users\Даниил\gradle-8.2\bin\gradle.bat assembleRelease -p C:\AstraLauncher
```

### Требования

- **JDK 17** (например, `C:\Users\Даниил\jdk17\jdk-17.0.20.1+1`)
- **Android SDK** (из `local.properties`)
- **Gradle 8.2** (`C:\Users\Даниил\gradle-8.2`)
- Путь к проекту **без кириллицы** (Android Gradle с ним несовместим) — поэтому проект в `C:\AstraLauncher`.

### Выходные файлы

| Вариант | Путь |
|---------|------|
| Debug | `app/build/outputs/apk/debug/app-debug.apk` |
| Release | `app/build/outputs/apk/release/app-release.apk` |

Релиз подписан ключом `astralauncher.keystore` (alias `astra`, пароль `astra123` — для личных целей).

## Установка

1. Скопируйте `app-release.apk` на телефон.
2. Разрешите установку из неизвестных источников (если нужно).
3. Установите приложение.
4. Нажмите кнопку **Home** — Android спросит, какое приложение сделать домашним экраном.
5. Выберите **Astra Launcher** и подтвердите.

> Приложение также появляется в списке приложений (категория `LAUNCHER`) — можно запустить и вручную.
